# 💼 Portfólio Pessoal - Samara Ramos

## 📌 Sobre o Projeto

Este projeto é um portfólio pessoal desenvolvido com **HTML5** e **CSS3**, com o objetivo de apresentar minhas informações, habilidades e projetos desenvolvidos durante minha graduação em Ciência da Computação.

O site possui um design moderno, responsivo e intuitivo, permitindo que visitantes conheçam um pouco mais sobre minha trajetória na área de desenvolvimento web.

---

## ✨ Funcionalidades

* Página inicial com apresentação pessoal.
* Seção "Sobre Mim".
* Exibição de projetos desenvolvidos.
* Layout responsivo.
* Menu de navegação com rolagem suave entre as seções.
* Links para GitHub e LinkedIn.
* Interface simples, organizada e de fácil navegação.

---

## 🛠️ Tecnologias Utilizadas

* HTML5
* CSS3
* Visual Studio Code
